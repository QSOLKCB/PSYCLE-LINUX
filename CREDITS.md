# Credits and Dedication

## In Memory of Arguru

PSYCLE-LINUX is dedicated to the memory of **Juan Antonio Arguelles Rius (Arguru)**.

Arguru's work is part of Psycle's identity, not merely a historical footnote. The r12005 C-Psycle source selected for this port still contains source for six Arguru machines:

- Arguru Compressor
- Arguru Distortion
- Arguru Goaslicer
- Arguru Reverb
- Arguru Synth 2f
- Arguru XFilter

Preserving those machines as functioning parts of Psycle on Linux is one of the project's explicit compatibility goals.

## The Psycle Community

Psycle was built by a community over many years. PSYCLE-LINUX recognizes the developers, plugin authors, testers, musicians, documentation contributors, bug reporters, and users who kept that ecosystem alive.

The historical `#Psycle` IRC channel was part of that community: a place where users and developers exchanged builds, test results, machines, songs, fixes, and ideas long before modern project chat platforms became normal.

PSYCLE-LINUX was started by **Trent Slade / QSOL-IMC**, who was part of the Psycle community in the 2000s and tested development builds during the Arguru era. The project is intended as a continuation and preservation effort—not a claim of ownership over Psycle's history.

## Attribution Rule

When upstream source is imported, the original `AUTHORS`, `COPYING`, source headers, plugin documentation, and third-party notices must be preserved.

If this credits document ever disagrees with an original upstream attribution notice, **the original upstream notice wins** and this file should be corrected.
